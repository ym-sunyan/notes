value 由用户自定义 规定 input 元素的值。注意: button类型时候value设置的是显示在按钮上的内容
checked checked 针对单选框和复选框. 规定此 input 元素首次加载时应当被选中。
maxlength 正整数 规定输入字段中的字符的最大长度。
size 正整数 规定输入字段的宽度，以字符为单位。

disabled disabled 规定输入字段被禁用。
placeholder 示例文本 规定在输入字段中显示的提示文本。
required required 规定输入字段在提交表单之前必须填写。
pattern 正则表达式 规定输入字段值必须匹配的模式（正则表达式）。
min, max 数值 规定输入字段的最小值和最大值。
step 数值 规定输入字段的合法数字间隔。
